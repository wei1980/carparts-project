# 車大師（Carparts）

唯一前端：`carparts-web`  
後端 API：`carparts-api`（固定 `http://localhost:3000`）  
`carparts-admin` 已退役。

啟動：`start_project.bat` 或 `啟動.bat`

- 商店：http://localhost:5173
- 管理後台：http://localhost:5173/admin
- 車廠後台：http://localhost:5173/garage/login
- API health：http://localhost:3000/health
